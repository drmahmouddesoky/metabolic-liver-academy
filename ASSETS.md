Update this file whenever you add or replace an image. Last checked: 24 October 2026.

## Rules for new images

1. Prefer images you make yourself, or drawings made in code.
2. For stock images, keep the licence page (screenshot or PDF) and add a row here.
3. For AI images, record the tool and date, and check its terms allow publication.
4. Never use images from journals, guideline PDFs, textbooks or Google Images without written permission. Citing the source is not permission.
5. No patient photos, ever.
